# tri-seconde-vie
🎮♻️ Tri &amp; Seconde Vie — Jeu éducatif sur le tri des déchets, le recyclage et le réemploi. 3 étapes : trier sur un tapis roulant, deviner la seconde vie des déchets, réparer des objets à l'Atelier Réemploi. Multilingue (FR/EN/ES), 3 niveaux d'âge, mode solo &amp; équipe, leaderboard. Par L'Oasis du Réemploi — Friendly Upcycling 🏠
